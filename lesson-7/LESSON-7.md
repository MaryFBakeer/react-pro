# LESSON-7 — Современная сборка фронтенд-приложений

Ветка: lesson-7

## Запуск

```bash
npm ci
npm run dev            # dev-режим: watch и сервер
npm run build          # prod-режим: tsc, приложение и библиотека через esbuild
npm run build:lib:swc  # библиотека через swc
npm run lint
```
